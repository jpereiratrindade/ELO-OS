# Identidade ELO

ELO: dois elos representam a continuidade entre conteúdo e encontro presencial.
ELO/OS: os mesmos elos em um módulo representam o sistema embarcado.
ELO-OS Client: os elos dentro de uma tela representam a apresentação no terminal.

SVGs de fundo transparente, viewBox 64 × 64, cor padrão #1a7dc4.
Ao incorporar o SVG inline, currentColor permite usar a cor do contexto.
As cópias em web/distribution são servidas pelo painel.
Prévia da família: preview.svg.

## Princípios de desenvolvimento

- `simple-light.svg`: pena, para “Simples, leve.” — poucos elementos e recursos proporcionais ao propósito.
- `always-ready.svg`: círculo com confirmação, para “Sempre pronto.” — uma realização utilizável no escopo atual.
- `always-incomplete.svg`: ciclo aberto, para “Sempre incompleto!” — evolução contínua e limites explícitos.

Esses símbolos representam compromissos de desenvolvimento; não indicam saúde ou conexão.
O lema também consta na constituição do ELO e nas interfaces MORFO, MÉTIS e EVIDA.
