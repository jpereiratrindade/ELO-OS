## Observações e limites

- Rootfs é RW após init; o snapshot protege o arquivo base no host. Não há `/data` persistente nem prova de tolerância a queda de energia.
- `root` sem senha é condição de bancada local; SSH e sudo não foram incluídos. `poweroff` desliga; `exit` retorna ao login.
- Dados manuais adicionais citados no plano (por exemplo ~13 MiB usados em `free -m`) vieram do operador. Não são meta de desempenho nem medição da futura interface Qt. O teste ampliado registra sua própria saída de `free -k`, sem impor limite artificial.
- A primeira execução longa teve erro do wrapper após o Make porque o script foi editado enquanto rodava; a reexecução incremental concluiu com saída 0. Nesta rodada os scripts de build/perfis foram concluídos antes do início do build ARM64.
- A primeira execução do novo parser de testes confundiu o prompt `# ` com o início da identidade. O teste falhou e o parser foi corrigido para aguardar o prompt entre comandos. Isso não foi falha da imagem; a regressão foi repetida após a correção.
- CI Q0 não reproduz estes boots. Pi 5, ARM64 e Qt não herdam os resultados x86.
