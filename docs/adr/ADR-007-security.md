# ADR-007 — Confiança e identidade

**Status:** proposed  
**Data:** 2026-11-08  
**Documento-base:** ELO-OS-BASES-001 v0.1.0

## Decisão

Identidade de dispositivo separada da pessoa; TLS validado, sem segredos distribuídos.

## Consequências e limites

Descoberta mDNS não autentica servidor.

## Critério de promoção

Mudar para `accepted` somente com revisão de implementação e evidência de teste correspondente.
