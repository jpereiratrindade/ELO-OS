# ADR-003 — Pacotes orientados por capacidade

**Status:** proposed  
**Data:** 2026-11-08  
**Documento-base:** ELO-OS-BASES-001 v0.1.0

## Decisão

Habilitar somente funções necessárias, com imagem P1 sem Qt.

## Consequências e limites

Adição de dependência requer justificativa e teste.

## Critério de promoção

Mudar para `accepted` somente com revisão de implementação e evidência de teste correspondente.
