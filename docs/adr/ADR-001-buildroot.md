# ADR-001 — Buildroot como sistema de composição

**Status:** proposed  
**Data:** 2026-11-08  
**Documento-base:** ELO-OS-BASES-001 v0.1.0

## Decisão

Usar Buildroot 2026.08.1 com árvore br2-external, preservando Pi 5 upstream; imagem é unidade de entrega.
