# ADR-006 — Conteúdo e eventos

**Status:** proposed  
**Data:** 2026-11-08  
**Documento-base:** ELO-OS-BASES-001 v0.1.0

## Decisão

Contrato ELO Server ↔ ELO Thin Client via HTTPS; hashes e eventos idempotentes.

## Consequências e limites

Rotas ainda propostas e não implementadas.

## Critério de promoção

Mudar para `accepted` somente com revisão de implementação e evidência de teste correspondente.
